# Часть A: линейные модели на разреженных признаках

Только классический ML, без нейросетей. Обучение на 80% `train`, замер на 20% `train` (валидация). Разбиение по товарам, `seed=0`. Тест (`data/splits/*_test.csv.gz`) замеряется в конце. Основная метрика — macro-F1, вторая — MAE. Мета-признаки (поля формы, длина, категория) относятся к части B и здесь не используются.

Ноутбуки:
- **`part_a_final.ipynb`** — основной: пошаговый отбор, на каждом шаге берётся лучший вариант (`results_final.csv`).
- `part_a_threshold.ipynb` — те же шаги, но более сложный вариант берётся, только если он лучше более простого больше чем на 0.003 (`results_threshold.csv`). Оставлен для сравнения.
- `part_a.ipynb` — исходные разведочные эксперименты (`results.csv`, раздел в конце).

## Пошаговый отбор (`part_a_final.ipynb`)

**Правило.** Каждый шаг меняет одну вещь. Берётся вариант с лучшим значением на валидации: macro-F1 или MAE, в зависимости от ветки. Исключение — шаг 2: в дальнейший отбор проходят все семейства моделей в пределах 0.01 от лучшего, и каждое настраивается отдельно. Ансамбль берётся, если он лучше всех одиночных моделей.

| Шаг | Что перебираем | WB | Amazon |
|---|---|---|---|
| 0 | Бейзлайн: TF-IDF слов и биграмм, logreg C=2, веса balanced | 0.4574 | 0.5224 |
| 1a | n-граммы: слова, +биграммы, +триграммы, символы 2–5, слова + символы | слова + биграммы + символы 2–5 (0.4595) | слова до триграмм (0.5237) |
| 1b | текст: сырой, нормализованный, стеммы, леммы | сырой | нормализованный (0.5253) |
| 1c | TF-IDF: raw/binary tf, 50k, полный словарь min_df=2 | полный словарь (0.4604) | полный словарь (0.5345) |
| 2 | 7 семейств, у каждого своя сетка регуляризации | лидеры: NB-SVM, LinearSVC, SGD, Ridge, logreg | лидеры: SGD, logreg, LinearSVC, Ridge |
| 3–4 | для каждого лидера веса × правило (argmax / сдвиги), затем регуляризация; цель macro-F1 | logreg без весов + сдвиги, 0.4852 | logreg без весов + сдвиги, 0.5455 |
| 5–6 | то же для MAE: argmax / медиана / сдвиги под MAE | logreg без весов + медиана, 0.2805 | logreg без весов + медиана, 0.2894 |
| 7 | ансамбль трёх лучших лидеров | 0.4826 / 0.2873 | 0.5462 / 0.3002 |
| 8 | финал: лучший из лидеров и ансамбля | logreg для обеих метрик | ансамбль для macro-F1, logreg для MAE |

Цифры — валидация (macro-F1, на шагах 5–6 — MAE, на шаге 7 — оба). На Amazon NB-SVM отстал на 0.015 и в лидеры не попал, Naive Bayes отсеян на обоих датасетах.

Финальные конфигурации:

| | Признаки | Модель | Веса | Правило |
|---|---|---|---|---|
| WB, macro-F1 | сырой текст; слова, биграммы, символы 2–5; полный словарь | logreg C=0.5 | без весов | сдвиги |
| WB, MAE | то же | logreg C=1 | без весов | медиана |
| Amazon, macro-F1 | нормализованный текст; слова до триграмм; полный словарь | ансамбль logreg + SGD + LinearSVC | свои у каждой | сдвиги |
| Amazon, MAE | то же | logreg C=2 | без весов | медиана |

**Тест** (модели обучены на всём train):

| | WB macro-F1 | WB MAE | Amazon macro-F1 | Amazon MAE |
|---|---|---|---|---|
| Бейзлайн | 0.457 | 0.368 | 0.520 | 0.382 |
| Вариант с порогом 0.003 (`part_a_threshold.ipynb`) | 0.482 | 0.292 | 0.540 | 0.309 |
| **Финал под macro-F1** | **0.486** | 0.296 | **0.548** | 0.333 |
| **Финал под MAE** | 0.482 | **0.274** | 0.536 | **0.306** |

- **Тест и валидация:** тест согласуется с валидацией. macro-F1 0.486 / 0.548 против 0.485 / 0.546, MAE 0.274 / 0.306 против 0.281 / 0.289.
- **Сравнение с вариантом с порогом:** жадный выбор лучше во всех четырёх ячейках, и на валидации, и на тесте. Мелкие приросты, каждый в пределах шума, складываются. В основном за счёт более богатых признаков: символьные n-граммы на WB, триграммы и полный словарь на Amazon.
- **Медиана для MAE:** в отличие от сдвигов под MAE, медиана сохраняет предсказания 2★. На WB F1 по 2★ 0.191 против 0.048 у варианта с порогом.
- **Цена:** с символьными n-граммами обучение на WB примерно в 5 раз дольше.

**Значимость на тесте** (парный бутстрап по товарам, 2000 повторов; разница — финальная модель минус сравниваемая, в скобках 95% интервал):

| | WB macro-F1 | WB MAE | Amazon macro-F1 | Amazon MAE |
|---|---|---|---|---|
| vs бейзлайн | +0.029 [+0.024, +0.035] | −0.094 [−0.101, −0.088] | +0.028 [+0.024, +0.032] | −0.076 [−0.081, −0.070] |
| vs вариант с порогом | +0.004 [−0.001, +0.009] | −0.018 [−0.022, −0.015] | +0.008 [+0.005, +0.012] | −0.003 [−0.005, −0.001] |

К бейзлайну все четыре улучшения значимы. К варианту с порогом значимы три из четырёх; на WB по macro-F1 прирост +0.004 на границе (вероятность, что жадный лучше, 0.95). На валидации порог 0.003 соответствует примерно 1.8 стандартного отклонения парной разницы двух моделей, так что каждый отдельный шаг жадного отбора в пределах шума, но вместе они дают значимый прирост.

## Разведочные эксперименты (`part_a.ipynb`)

### Как запустить

```bash
python ml/prepare_splits.py                          # train/test, если ещё нет
python experiments/part_a/run.py                     # все эксперименты, оба датасета (~3–4 часа)
python experiments/part_a/run.py --datasets wb --groups combo
python experiments/part_a/summarize.py > experiments/part_a/RESULTS.md
```

- **Перезапуск:** уже записанные эксперименты пропускаются, поэтому прогон можно прерывать и продолжать.
- **Файлы:**
  - `results.csv` — сырые результаты, одна строка на эксперимент вместе с полным конфигом;
  - `RESULTS.md` — таблицы по группам;
  - `experiments.py` — все конфиги;
  - `common.py` — данные, признаки, модели, декодирование, метрики.

### Что перебирали (140 экспериментов: 71 на WB, 69 на Amazon; лемматизация и фильтр отзывов о доставке только на WB)

| Группа | Что меняется | На чём |
|---|---|---|
| `features` | n-граммы (1–3), размер словаря, sublinear/binary tf, символьные n-граммы, метки полей и флаги, мета-признаки (длина, пунктуация, эмодзи, категория), нормализация, стемминг, лемматизация | logreg C=2 с весами классов |
| `models` | logreg (C), LinearSVC (C), SGD (hinge / log / modified_huber), RidgeClassifier, ComplementNB, MultinomialNB, NB-SVM, passive-aggressive | лучшие признаки |
| `imbalance` | без весов, balanced, sqrt-веса, андерсэмплинг всех классов или только пятёрок, оверсэмплинг | лучшие признаки |
| `data` | удаление из train коротких отзывов, дубликатов, отзывов о доставке (валидация не меняется) | лучшие признаки |
| `decoding` | медиана распределения (для MAE), сдвиги порогов по классам под macro-F1, ridge-регрессия + пороги | лучшие признаки |
| `selection` | отбор признаков по χ² (20k / 50k / 100k) | лучшие признаки |
| `combo` | лучшие находки вместе | лучшие признаки |

Сдвиги и пороги подбираются на out-of-fold предсказаниях train (3 фолда по товарам). Валидация в подборе не участвует.

### Итог

| | WB macro-F1 | WB MAE | Amazon macro-F1 | Amazon MAE |
|---|---|---|---|---|
| Бейзлайн: TF-IDF 1–2 + logreg C=2, веса классов | 0.457 | 0.371 | 0.522 | 0.369 |

Лучшие признаки:
- **WB:** слова и биграммы + мета (флаги полей, длина, пунктуация);

### Выводы

1. **Больше всего даёт правило принятия решения, а не признаки.** Модель без весов классов со сдвигами порогов, подобранными под macro-F1, лучше, чем веса классов при обучении: +0.02 на обоих датасетах. Веса искажают вероятности, а сдвиги корректируют только итоговое решение.
2. **Под каждую метрику — своё декодирование.** Сдвиги порогов максимизируют macro-F1, медиана распределения минимизирует MAE. Одну модель можно отдавать с разными правилами в зависимости от метрики.
3. **Регуляризация:** у logreg лучшие C = 0.5–1, у LinearSVC — C = 0.03 на WB и 0.1 на Amazon. При более слабой регуляризации качество падает.
4. **Признаки дают мало:** биграммы +0.025, мета-признаки и полный словарь +0.002–0.004.
5. **Отрицательные результаты:**
   - Символьные n-граммы: одни хуже слов на 0.014–0.025 и обучаются в 4–6 раз дольше. Вместе со словами не помогают logreg, но добавляют 0.007–0.008 линейному SVM, который всё равно остаётся ниже logreg.
   - Лемматизация и стемминг: на уровне нормализации текста.
   - Категория товара: не помогла.
   - Отбор признаков по χ²: не помог.
   - Андерсэмплинг: до самого редкого класса — худшие macro-F1 и MAE (0.437 / 0.437 на WB). Только пятёрок — F1 по 2★ падает до 0.058 на WB.
   - Naive Bayes: ниже логистической регрессии.
   - Ridge-регрессия с порогами: хуже классификации.
   - Чистка train: на уровне шума.
6. **Модели:** с весами классов лучший — LinearSVC (0.468 / 0.530). В лучшей схеме (без весов + сдвиги) выигрывает logreg. NB-SVM почти наравне с ней (0.480 на WB) и хороший кандидат в ансамбль, SVM и Ridge немного хуже.
7. **Самые трудные классы — 2★ и 3★:** F1 0.19 и 0.33 на WB, 0.32 и 0.39 на Amazon.

### Дополнение: word2vec и Optuna

Эти две группы есть только в `part_a.ipynb` (их нет в `experiments.py` и `RESULTS.md`). Всего в `results.csv` теперь 168 запусков.

| | WB macro-F1 | WB MAE | Amazon macro-F1 | Amazon MAE |
|---|---|---|---|---|
| Только векторы, лучший вариант (SVM) | 0.402 | 0.547 | 0.469 | 0.526 |
| TF-IDF + векторы с IDF + сдвиги (`w_best_idf_bias`) | 0.485 | 0.307 | 0.544 | 0.314 |
| TF-IDF + средние векторы + медиана (`w_best_mean_median`) | 0.476 | **0.285** | 0.534 | **0.293** |
| Optuna, 40 trial (`opt_best_bias`) | 0.475 | 0.309 | 0.542 | 0.311 |

- **word2vec:** на macro-F1 прирост в пределах шума (+0.001 / +0.001), обучение в 5–7 раз дольше. Заметное улучшение только на MAE с медианой. На WB (RusCorpora) покрыто около 63% токенов: в модели нет служебных слов, в том числе «не».
- **Optuna:** подбор идёт внутри fit, валидация оценивает только лучший конфиг. Оба поиска сошлись к NB-SVM почти без весов классов, но результат ниже ручного лучшего (0.484 / 0.544).
- Векторы скачиваются в `~/gensim-data` (около 1.9 ГБ), `optuna.db` хранит trial.

### Модель только на тексте, тест (разведочная версия)

Мета-признаки относятся к части B, поэтому финальная модель использует только текст. Лучшие признаки выбираются среди вариантов без мета-признаков (группа `text_only` в ноутбуке). На WB это нормализованный текст, слова и биграммы (`f15_clean`). На Amazon набор тот же, что и раньше: слова до триграмм, 300k признаков. Модель: logreg C=1 без весов классов. Для macro-F1 используются сдвиги порогов, для MAE — медиана распределения.

Тест замерен один раз. Модель обучена на всём train, сдвиги подобраны на 3 фолдах train по товарам.

| | WB macro-F1 | WB MAE | Amazon macro-F1 | Amazon MAE |
|---|---|---|---|---|
| Валидация, сдвиги | 0.482 | 0.308 | 0.544 | 0.316 |
| Валидация, медиана | 0.467 | 0.287 | 0.532 | 0.294 |
| **Тест, бейзлайн** | 0.457 | 0.368 | 0.520 | 0.382 |
| **Тест, сдвиги** | **0.484** | 0.301 | **0.546** | 0.325 |
| **Тест, медиана** | 0.470 | **0.281** | 0.532 | **0.311** |

Без мета-признаков WB теряет на валидации 0.0016 macro-F1, это в пределах шума, а MAE с медианой даже лучше. Тест согласуется с валидацией.

**Известное ограничение:** passive-aggressive реализован через `SGDClassifier(learning_rate='pa1')`, и параметр C в нём фактически не используется. Поэтому два запуска PA одинаковые. Модель слабая (0.399 на WB), на выводы это не влияет.
